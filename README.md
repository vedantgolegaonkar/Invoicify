# Invoicify

A comprehensive billing, invoicing, and inventory management application built with Flutter and Firebase.

## Features
- **GST & Tax Invoices:** Generate professional PDF tax invoices with itemized HSN/SAC codes.
- **WhatsApp PDF Sharing:** Share branded PDF invoices directly with customers via WhatsApp.
- **UPI QR Codes:** Integrated UPI QR code for fast payments (GPay, PhonePe, Paytm).
- **Customer Ledger:** Track customer balances, payments, and outstanding receivables.
- **Inventory Management:** Live stock monitoring with low-stock alerts.
- **Business Reports:** Sales, collection, and GST reports.
